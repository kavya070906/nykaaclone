# Nykaa Man visual recreation

Buildless website with Home, Profile, and Orders pages.

Run `python -m http.server 8000 --directory dist` from this folder, then open http://localhost:8000. No dependencies or build required.

The Orders page contains two sample delivered orders: the Perch shirt and Jean Paul Gaultier fragrance. Delivery dates are 11 August 2026 at 2:35 PM and 3:10 PM IST. Their DEMO order IDs are fictional. Order Details buttons expand inline. Layouts adapt to mobile, tablet, and desktop, including navigation, campaign rails, profile editing, and footer columns.

All order records are static demonstration content, not live purchase records. Profile editing and addresses use browser-local storage. Product links open Nykaa Man in a new tab.

The public repository uses demo profile information. Edits remain local to your browser.
