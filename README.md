# Nykaa Man visual recreation

Buildless website with Home, Profile, and Orders pages.

Run `python -m http.server 8000 --directory dist` from this folder, then open http://localhost:8000. No dependencies or build required.

The Orders page adapts the supplied mobile reference for desktop, retaining the Nykaa Man header, sidebar, and teal theme. Order Details buttons expand inline. Two reference cards show delayed dispatch; two additional sample orders show the requested Perch shirt and Jean Paul Gaultier fragrance, dated 11 August 2026 at 2:35 PM and 3:10 PM IST. Their DEMO order IDs are fictional. The first two thumbnails are recreated illustrations; the added product images come from the supplied product pages.

All order records are static demonstration content, not live purchase records. Profile editing and addresses use browser-local storage. Product links open Nykaa Man in a new tab.
